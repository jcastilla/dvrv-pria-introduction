# PRIA01 Tarea01

Tarea relacionada con el tema **UT01.- Introducción a la programación en un motor de videojuegos**.

## 🎯 Objetivo
Demostrar la correcta instalación de **Unity3D** y aplicar un script básico de movimiento para desplazar un cubo sobre un plano utilizando las teclas **WASD**.

## 🛠️ Tecnologías utilizadas
* **Motor de videojuegos:** Unity3D
* **Lenguaje de programación:** C#

## 🎮 Controles
* **`W`** / **`S`**: Mover hacia adelante y hacia atrás.
* **`A`** / **`D`**: Mover hacia la izquierda y hacia la derecha.

## 🚀 Cómo probar el proyecto
1. Clona este repositorio o descarga el código fuente.
2. Abre **Unity Hub** y selecciona **Add** (Añadir) apuntando a la carpeta raíz del proyecto.
3. Abre la escena principal ubicada en la carpeta `Assets/Scenes`.
4. Pulsa el botón **Play** en la parte superior del editor de Unity para probar el movimiento.
